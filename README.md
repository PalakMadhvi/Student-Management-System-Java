# Student Management System

A Java-based Student Management System developed using Object-Oriented Programming (OOP) and ArrayList.

## Features

- Add Student
- View Student Records
- Update Student Information
- Delete Student Records
- Duplicate Roll Number Validation
- Marks Validation (0-100)
- Invalid Input Handling

## Technologies Used

- Java
- OOP Concepts
- ArrayList
- Scanner
- VS Code

## Concepts Used

- Classes and Objects
- Constructors
- Methods
- Encapsulation basics
- ArrayList
- Loops
- Conditional Statements
- Switch Case
- Input Validation

## How to Run

1. Clone or download the repository.
2. Open the project in VS Code.
3. Compile the Java files.
4. Run `Main.java`.
5. Use the menu to manage student records.

## Project Purpose

This project was developed as part of a Java Programming Internship to gain practical experience in Java programming and data management.
